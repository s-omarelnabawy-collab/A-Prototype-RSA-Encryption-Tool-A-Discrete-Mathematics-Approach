# RSA Encryption Suite (MATH 203)

A Python-based graphical user interface (GUI) application that brings the RSA encryption algorithm to life. Developed as a practical implementation for a Discrete Mathematics course, this prototype bridges the gap between abstract number theory and functional software development.

The complete theoretical framework, mathematical methodology, and system design can be found in the accompanying **Discrete Math (MATH 203) – Project Report.pdf** file.

## Features
* **Key Generation:** Computes public and private keys using the Extended Euclidean Algorithm based on user-inputted prime numbers p and q.
* **Encryption Module:** Converts plaintext into numeric ciphertext using modular exponentiation.
* **Decryption Module:** Recovers the original text seamlessly using the mathematically linked private key.

## Tech Stack
* **Language:** Python 3
* **GUI Framework:** Tkinter
